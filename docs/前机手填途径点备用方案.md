# 前机手填途径点备用方案

编辑 `src/zyc_fuel_ws/src/FUEL/fuel_planner/exploration_manager/config/manual_waypoints.yaml`：

```yaml
mission:
  manual_path:
    enabled: true
    arrive_distance: 0.25
    waypoints:
      - [1.0, 1.5, 0.8]
      - [1.0, 3.0, 0.8]
      - [2.5, 3.0, 0.8]
```

以上仅为格式示例，使用前替换为实际场地坐标。坐标是前机 FAST-LIO 里程计的世界系
（当前为 `UAV0/camera_init`），单位米，不能直接填写 MAVROS 局部坐标或机体相对位移。
`z` 是同一世界系内的高度坐标。

修改后重启前机规划器，原有六分屏/七分屏启动入口会加载这个文件，无需增加启动命令。
`enabled: false` 恢复原有自动路径；默认关闭。

普通通道搜索仍自动选择前沿观察目标，但当前位置到该目标的几何路径改为：
当前位置 → 列表中尚未到达的点 → 本轮自动选择的前沿目标。
手填列表是一条按顺序使用的备用路线，不会在每次前沿重选时从第一个点重新开始。
只有实际里程计进入当前点的 `arrive_distance` 三维半径后才推进列表。
重启规划器会从列表开头重新开始。

每轮以当前下一个手填点作为轨迹段终点，避免跨点平滑切弯。
列表用完后直连本轮自动选择的前沿目标；空列表同样表示直连。
此模式跳过普通搜索路径的 A* 搜路、路径缩短、直线延伸、自动短段截取及动力学重新搜路。
轨迹仍由原有样条生成器生成连续的位置、速度和加速度参考；共线插值和时间采样仍然存在。
原有动态避障可能调整轨迹，原有地图、机体足迹和任务边界检查仍可能拒绝该段。
轨迹检查失败时不改发自动截取的短段，继续保留当前手填点。

该开关只替换普通搜索路径。入口、出口/降落任务，以及原有专用竖直绕障、原地转向和脱困流程
仍按原逻辑运行。前沿目标仍会随搜索更新，坐标列表应按实际通道的行进顺序填写。
