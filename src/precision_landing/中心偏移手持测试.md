# 物理机体中心偏移测试

本入口只启动下视相机和观测节点，不依赖雷达、MAVROS、OFFBOARD 或解锁。
使用独立本机 ROS master（11440），复用精降 ArUco 检测库和
`config/precision_landing.yaml` 的 50 cm 码尺寸及相机外参。
不要同时运行其他占用下视相机的启动入口。

拆桨、保持未解锁，手持或用支架将飞机水平放在码上方约 1.2 m。
用铅垂线对准物理机体中心与码中心；仅凭图像居中不能确定物理中心。

启动（默认 ArUco ID 为 2，其他码用 `marker_id:=数字`）：

```bash
bash /home/asus/match_ws/src/precision_landing/scripts/start_center_offset_test.sh
```

终端显示 X 向前、Y 向左的厘米读数及相对码高度。
原始数据：`/UAV0/center_offset_observer/target_body`；
调试图：`/UAV0/center_offset_observer/debug_image`。
这些是观测话题，不是飞行节点的误差话题。

中心对准并保持稳定后，在另一终端采样：

```bash
bash /home/asus/match_ws/src/precision_landing/scripts/start_center_offset_test.sh sample
```

每次采样 10 秒，保存到 `~/target_reports/center_offset/`，含均值、标准差、
样本数、时间覆盖和最大间隔。`quality_review_needed` 只检查样本质量，
即便为 false 也不能证明飞机已物理居中或水平。
丢码时不发布有效样本；无足够数据时不生成偏置结果。

`candidate_center_bias_xy_m` 是待复核的中心偏置：实际居中时现有算法的 XY 均值。
以后若采用它，应使用“观测 XY − 偏置 XY”计算对准误差。
此工具不修改外参或精降配置，也不能由单次静态对准求出完整旋转、平移外参。
至少重复两次，并更换高度复测；偏置随高度明显变化时不能直接采用固定补偿。

退出启动终端用 Ctrl+C。测试完成后无需启动任何飞行任务。

## 当前UAV0试验补偿

用户指定使用 `20261013_213049_403012.yaml` 与
`20261013_213623_589262.yaml`，分别599帧、600帧，两组等权平均得到
`[0.13725125550231387, -0.015099632412342412]` 米。
两组前向均值仍差约4.45厘米，该值按用户选择作为试验补偿，不表示完整外参标定通过。

2026-10-14，用户反馈从地面码中心起飞后，机体中心落在码中心后方约20厘米、
左侧约10厘米，并明确要求按该落点修正。因此当前补偿改为
`[-0.06274874449768614, 0.0849003675876576]` 米（原X减0.20、原Y加0.10）。
预期将对准目标相对原配置向前移20厘米、向右移10厘米；这是目测修正，尚未复飞验证。
独立测试和总流程均加载该配置，修改后需在地面重启精降节点才能生效。

正式 `precision_landing.launch` 仅在 UAV0 下加载
`config/center_offset_uav0.yaml`。补偿作用于视觉水平控制、对准门限和
`/UAV0/landing/error_xy`，不改变视觉高度或相机外参。
中心观测入口仍输出未补偿的原始机体系坐标，避免后续重复标定时叠加补偿。
12 cm / 0.5秒低空门限保持不变；如需取消补偿，将该文件的两项设为0。
