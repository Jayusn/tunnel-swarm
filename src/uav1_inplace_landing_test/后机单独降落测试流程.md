# 后机原地起飞精降独立测试

同步前机 2026-10-14 已验证的 NMPC 精降源码，原始文件哈希见 SOURCE_MANIFEST.txt。
专用包和可执行文件不覆盖后机总流程的 MPC 或精降。

在后机桌面关闭其他飞行流程后执行：

```bash
bash /home/oem/match_ws/shfiles/start_uav1_inplace_landing_test.sh
```

待定位和下视画面正常后，在另一终端执行（此命令会起飞）：

```bash
bash /home/oem/match_ws/shfiles/start_uav1_inplace_landing_test.sh start
```

默认 NMPC 测试在启动待命时就自动开始诊断录包，不需要额外启动监测，也没有 5 分钟限制。
记录覆盖等待、解锁、起飞和降落，关闭测试流程时结束。
在原有飞控状态、遥控器输入和精降状态之外，同时记录飞控系统健康、估计器状态、
飞控文字提示、接收到的原始 MAVLink（包含命令回执）、`/diagnostics` 和 `/landing_test/status`，
用于回看解锁失败的原因及时间线。录包只订阅信息，不发送解锁、切模式或起飞指令。
文件沿用现有目录 `~/.ros/autotrans_mpc_logs/`，每次运行生成独立目录，
标签为 `precision_fixed_xy_descent`，其中 `.bag` 是完整记录，`*_rosbag.log` 是录包日志。
本次更新需重新启动单独测试流程后生效；起飞命令、爬升时间和降落参数保持原值。

使用后机本机 ROS master 192.168.43.21，飞控接口为 UAV1。
目标起飞高度 1.7m，MPC 起飞目标用 5 秒爬升；50cm ArUco，任意 ID。
执行 `start` 后，预流、切 OFFBOARD 和等待解锁共用原有 30 秒时限；
在此时限内确认解锁后，重新计时，起飞、到位稳定和精降交接另有 30 秒。
因此解锁等待不会挤占爬升时间；解锁前或起飞后各自超时仍进入原有保持状态。
起飞航向在已解锁且 OFFBOARD 接管时按当前 MAVROS 航向锁存，起飞期间保持；
不沿用执行 start 时的旧航向，避免等待解锁期间航向重对齐导致突然转向。
相对码高度不高于 1.3m 且水平误差不超过 12cm 连续 0.5 秒后锁 XY；
估计距码面 0.3m 时切 AUTO.LAND。CH10 可优先打断。

单独测试的中心补偿位于 `config/standalone_center_offset.yaml`，由 `landing_test.launch`
在公共精降配置之后加载。针对实测向机头偏约 12cm，X 补偿由 0.04000405m
增加到 0.16000405m，Y 保持 -0.04328857m。控制误差为测量值减补偿，
因此该调整将视觉对中目标向机尾移动 12cm；实际落点改善需实飞复核。
撤回此前试调的 5cm / 1 秒覆盖，沿用原来的 12cm / 0.5 秒及其余控制参数。
重启单独测试流程后生效，实飞确认后再同步多机方案。

独立 NMPC 收到 `FIXED_XY_DESCENT` 状态及该阶段的位置目标后，
一次性锁存当前 FAST-LIO 的 XY 和 Z。后续保持该 XY，Z 只叠加精降目标的下降增量，
避免起飞时保存的 MAVROS→FAST-LIO 变换在末段造成锁点偏移。
该锁存修正不改变视觉对准门槛；下降位置跟踪误差仍需实飞复核。

相机内参使用后机 ~/.ros/camera_info/down_camera.yaml，外参使用后机
precision_landing/config/down_camera_extrinsic_uav1.yaml。
多机的机体中心补偿继续使用 `config/center_offset_uav1.yaml` 中的后机标定值；
单独测试使用上述专用补偿文件。
MPC 模型、推力和调参由后机原 payload_mpc_controller/config 覆盖默认值，
保留后机质量 1.836kg 和已有调参。State 超时为 1.5 秒以兼容飞控 1Hz 状态。

当前独立测试用于落点左偏对照：X/Y 外力补偿增益为 0，Z 增益为 1。
水平外力仍估计和记录，但不应用于控制；重启测试流程后生效。

源码副本用于复现本次确认版本；后续前机改动不会自动更新此包。

兼容调整：后机 PolynomialTraj 消息无 has_yaw/yaw_trajectory 扩展，测试副本移除该可选规划轨迹解析；精降航向仍由 PositionTarget.yaw 给出。

复制源码仅清理行尾空白，SOURCE_MANIFEST 记录清理前的前机原始文件哈希。

## 六窗口双机流程的精降接入

`bash /home/oem/match_ws/shfiles/start_uav1_six_terminator.sh` 已启用任务精降。
六窗口流程继续由原来的平台分配、UAV0 放行和搜索节点触发 `/UAV1/need_to_land`，
随后使用本包的视觉精降节点、50 cm 码参数、UAV1 相机外参和 `center_offset_uav1.yaml` 中的中心补偿。

视觉目标经仲裁器转发到 `/UAV1/landing/nmpc_target`，由原任务 NMPC 执行，
不再直接把视觉位置指令送给飞控。末段进入 `FIXED_XY_DESCENT` 后，锁住当时 FAST-LIO 的 XY，
Z 只跟随精降目标的下降增量，抵达既有 0.30 m 截止高度后请求 PX4 `AUTO.LAND`。
精降期间水平外力补偿为零，正常任务阶段保持原配置。CH10 打断后继续走任务控制器原来的降落逻辑，
视觉精降停止输出和切模式请求；再次测试前重启流程。

此入口不启动独立测试的自动解锁/起飞节点，也不需要再运行 `start_uav1_inplace_landing_test.sh start`。
独立测试中的起飞高度 10 cm 容差仍只属于独立测试；总流程的起飞与接力航点条件不变。
降落 rosbag 同时记录下视原图、相机参数、MAVROS 位置和精降状态/目标，便于复核落点。
