# 原始点云运动证据实验（2026-10-15）

## 行为与边界

新增默认关闭的 `detection/object_motion_evidence_enabled`。开启后，`general` 和
`swing-only` 均采用同一种运动确认，不再要求换向，也不受本地工作区额外的 0.5 秒
连续性拟合门槛影响。关闭时保留原路径。本轮验收失败，七分屏保持原来的 `swing-only` 默认；新开关保持关闭。

每个候选使用当前稠密原始点，在上一观测的完整原始点云中分别查询原位置和按实测
中心位移移回的位置；匹配半径保持 5 厘米。移动匹配率和相对静态匹配优势都需达标。
深度证据取新位置曾为空闲与旧位置已腾空两者比例的最大值；遮挡、未扫描依旧未知，
分母包括未知点。连续三个有效观测中的两次相邻转移均需满足这三项阈值。

保留原有运动幅度、速度、背景、形状、点数、跟踪和 0.6 秒退出保持；新证据不提供
额外恢复通道。形状检查沿用摆动路径对启动阶段和稀疏点的检查。聚类、中心计算、
关联代码、四路消息与话题均未改动。已确认目标的保持不意味着每一帧都重新满足
两次运动证据；这是原有退出行为。

参数：

| 参数（前缀 `detection/`） | 冻结的失败复核值 |
| --- | ---: |
| `object_motion_evidence_enabled` | `false` |
| `object_motion_match_fraction` | 0.45 |
| `object_motion_match_advantage` | 0.30 |
| `object_motion_depth_fraction` | 0.40 |

这组参数未达标；开关保持关闭。初轮筛选使用 0.45／0.10／0.20，冻结复核使用
上表同一组参数覆盖全部场景。显式试验启动：

```bash
roslaunch mot_mapping uav1_frame_event_verified.launch \
  dynamic_mode:=general object_motion_evidence_enabled:=true
```

## 验证方法

原始源码、工作区差异和原可执行文件保存在
`/home/oem/fapp_motion_evidence_20261015/before`、`before.diff`、`baseline_mapping_node`。
所有录包单检测实例、原生速率顺序回放，使用独立本机 ROS master。
球、墙面、无目标及最新录包使用约 10 Hz 的原始注册云；历史静止包现存的
输入只有 468 帧／122 秒的节流云，不能称为原生 10 Hz 静止验证。其原始
`.bag.active` 已不在原路径，现有 static 回放包也未保存原始注册云。
对照采用同一份配置和输入：

- `baseline_clean`：原始摆动路径，连续性时长为 0（与七分屏摆动入口一致）。
- `ablation`：独立编译原始源码副本，仅令最后的摆动发布门槛不执行；保留摆动路径
  的形状检查、运动参数及发布前反馈，避免直接用 general 引入额外差异。
- `evidence`：开启新开关，其余参数同基线。

历史球使用冻结的 113 个 `points >= 6` 标注，中心距离 < 0.25 米、最大边长 < 0.65 米
才算命中；缺输出的有效标注仍留在分母。负样本帧数按有非空 states 的帧计数，
连续误报事件按相邻输出帧的非空连续段计数，时间间隔 > 0.25 秒也断开事件；
不是框数量或跨帧物体数量。四路一致性核对时间戳和对象数量。

27 组阈值在冻结候选/关联记录上离线筛选，筛选输出是估计值，不能替代实际回放：
发布反馈可能影响丢失重获时的关联。候选组合必须完整回放后才能用于验收。
所有场景共用一组阈值，最新录包不能用于再次调参。

`output_record_lag_seconds` 是 bag 记录时间与输入 header 时间的差，表示回放时
的输出积压近似值，不等同于算法从运动开始累计的证据时长。

这 819 个有效标注在两轮中均有对应输出时间戳，未因丢帧减少分母。首次运动区间

对 819 个有效标注，邻近（<0.25 米）运动证据记录有 584 帧，有效观测 410 帧，
有效相邻转移 377 帧，满足两次运动证据 88 帧；输出可由原有 0.6 秒保持延续，因此
输出命中数大于当帧证据确认数。候选不连续、上游背景/形状判定和运动证据不足均
影响最新片段，仅替换末端确认不能消除这些漏检。这里没有修改聚类或关联来追结果。

最新录包的原生 10 Hz、前 26.5 秒静态外观片段另有非空输出基线 5 帧、冻结版 8 帧；
没有逐点覆盖整个雷达视场的静态真值，故只记为补充输出统计，不冒充独立负样本结论。

### 为什么墙面仍会通过

墙面实测候选也会得到很强的“运动”证据。例如 `1791948653215660810`、轨迹 301，
移动匹配 0.75、静态匹配 0.0833、双向深度比例 0.6667。它们足以通过本轮阈值，
说明“平移后匹配更好”加局部观测腾空并非该数据中可靠的物体级运动判据。
结合静态场景的碎片位置跳动，重复表面、扫描落点变化及片段关联是后续排查方向；
这里是由日志作出的解释，不是已经完成的独立因果验证。原有保持还会延长一次误确认。
