# 点级运动证据对照（2026-10-10）

**本轮九组结果均未通过联合验收。** 冻结背景发布抑制使独立原型无球框从1884降到493，球命中保持90/113；但初始静止126框、返回144框仍超过固定门槛109/96，球命中也不足108/113。双向腾空证据最高94/113，却明显增加无球框。点云同期校正TF没有改善。正式FAPP入口保持用户选定的 **10 Hz、A04＋点源竞争、20 cm真实目标、普通三帧确认**，本轮方法未启用为默认。

本报告是独立点级原型离线筛查，不能替代当前正式A04检测率。累计框是误检代理，并非真实误检率；本轮也没有证明整机闭环避障达标。

原型普通三次实测、6 cm位移、0.14 m/s、0.82 m一对一关联、连续轨迹优先、启动新点0.26/已发布轨迹0.20保持不变。射线查询使用真实返回的3 cm横向邻域和3 cm深度容差；本原型采用角度KD邻域查询，未声称实现完整M-detector或生产0.25°角度网格。实际20 cm目标不等于点簇包围尺寸，不增加小于20 cm就删除的条件。

## 位姿对照与失败诊断

新球1727云全部具有相同header的实录 `UAV1/camera_init → UAV1/body` 映射TF。最近HF与它的雷达原点差p50为0.875 mm、p95为3.341 mm、最大16.657 cm；转角差p95为0.241°、最大15.029°。查询仍使用实际FAST-LIO雷达外参 `[-0.011,-0.02329,0.04412]`。同期TF方案只换位姿源，不改世界云，不插值或生成位姿，结果未改善。

无球紧凑evaluation副本未保留TF，首次尝试在算法前断言失败；随后从原9.468 GB `.bag.active` **只读**提取763条真实映射TF到独立文件，原文件大小和mtime不变，再完成763云精确header覆盖对照。不能将紧凑副本缺TF误报为原始录包缺TF。新球TF trace里的 `pose_dt_ms` 是继承的HF参考年龄，不能当作所选TF年龄；精确TF覆盖由源代码lookup断言和位姿审计证明。

另完整只读核对1727帧、16607010个注册点：虽然消息含 `curvature` 字段，但全部值为0，没有可用逐点采样时间。现有FAST-LIO世界点转换仅复制x/y/z/intensity，注册云发布不传递原采样时间。本轮不改FAST-LIO；后续可以继续帧级证据试验，但不能从这些0值声称恢复真实逐点事件时间，或套用完整M-detector的逐点时延。字段核对及源码哈希见结果JSON的 `input_point_time_audit`。

这些方法在所有113时刻都有合格几何候选，全部冻结时刻有输出；本轮主要缺口转为运动证据和新点判据。双向证据减少事件不足，却把更多时刻移到新点不足，并放出大量静态框，不能只按球召回推荐。历史单项证据支持上限为96/113；前一轮原始缓存的事件＋已发布新点支持上限90/113。它们只限定对应固定候选/规则，不能当作物理检出上限。下一轮应区分真实动态表面与历史占用、检查静态参考来源，单独回放点级事件来源变化，不盲目调整三帧、位移或速度门槛。

## 计算优化与计时边界

新增独立 `density_peak_candidates.py` 将原始点DBSCAN分组切片及候选包围框、事件计数、两历史最近点比例合批计算；**正式ROS节点没有调用它**。固定8 cm密度分区和6点要求沿用前一轮独立试验，没有增加类别或20 cm包围尺寸过滤。

全1727相同原生云配对验证交替先运行旧/合批核心，全部427732候选、逐点事件/静态、成员、中心尺寸、新点、轨迹、决策及发布指纹差异 **0**；累计4203框不变。旧核心p50/p95为265.02/388.56 ms，合批240.55/351.24 ms，配对平均减少21.95 ms；p95下降9.61%，仍超过100 ms。移入仓库的原始无权重分支经规范化AST一致及前120帧完整指纹零差异验证；事件优先对照再次复现全部1727发布和427732候选。这证明计算等价，不证明生产PCL等价或检测正确。

同期TF对照每个方案单独计算几何与新点，完整离线核心新球p95为基线218.71、TF220.17 ms，无球234.79/234.53 ms。两次F/V新球合成核心p95为462.05 ms；背景抑制的新球合成核心p95为223.78 ms，其98.03 ms只是排除共享几何的新方法分量。不能把分量小于100 ms当作整回调通过。

所有时间来自离线并发筛查，排除ROS解码、同步、消息构建和发布；共享几何试验的“合成核心”是同帧共享几何加各方案分量，未证明独立实时执行成本。不同运行的负载不同，不跨运行推导CPU占用或因果加速。旧142、静止467、四路输出、CPU、RSS及持续回调积压本轮未跑，结果明确为null。已失败的动态/无球单项不进入默认配置，也不因省略其他门槛而声明通过。
