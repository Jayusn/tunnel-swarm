# 原候选与新增组件关联隔离实验（2026-10-15）

用户明确授权后增加默认关闭的 `association/object_candidate_isolation_enabled`。
开启时，原始 DBSCAN 候选与 `object_candidate_split_enabled` 新增组件仅在各自来源内
参与现有贪心关联。来源独立于旧的 `supplemental_candidate`，不引入其父簇发布依赖。
若同时开启旧 `candidate_partition_enabled`，它追加的候选继承父候选来源。

保持候选提取、中心、关联距离及排序、背景与形状检查、运动证据阈值、确认和退出
逻辑不变。物体在原候选与组件之间切换时可能断轨或重复出框，隔离并非去重。
未增加状态机、恢复策略或过滤条件。开关关闭时不限制来源；无新增组件时全部来源为
原候选，隔离不起作用。七分屏默认不变。

```bash
roslaunch mot_mapping uav1_frame_event_verified.launch \
  dynamic_mode:=general object_motion_evidence_enabled:=true \
  object_candidate_split_enabled:=true object_candidate_isolation_enabled:=true
```

## 完整历史回放结果：验收失败，保留默认关闭

| 指标 | 原摆动基线 | 原运动证据 | 追加组件未隔离 | 追加组件隔离 |
| --- | ---: | ---: | ---: | ---: |
| 历史球有效标注检出 | 45/113 | 101/113 | 89/113 | 100/113（88.5%） |
| 墙面误报帧／事件 | 1/1 | 34/6 | 45/2 | 45/1 |
| 无球误报帧／事件 | 9/4 | 187/20 | 179/27 | 219/28 |
| 静止误报帧／事件 | 0/0 | 0/0 | 0/0 | 0/0 |
| 同一球标注附近多个合格框的帧数 | 0 | 0 | 8 | 5 |

隔离版的 2 个有效标注没有输出，已按漏检计入 113 帧分母；状态与框各命中 100 帧。
相比未隔离追加组件版，补回 13 帧、另失去 2 帧，净增 11 帧；之前相对原运动证据版
新增的 13 个漏检帧全部恢复。另失去的 2 帧中 1 帧无输出，另 1 帧有输出但未命中。
这支持关联竞争会影响球轨迹的判断，但实时回放存在处理时间和输入历史差异，不能声称
排除了所有混杂因素。每个命中标注最多计一次；隔离版仍有 5 帧出现两个合格球框。

| 隔离版场景 | 输入数 | 未进入回调数 | 处理 P95 | 输出记录积压 P95 |
| --- | ---: | ---: | ---: | ---: |
| 历史球 | 1727 | 270 | 157.12 ms | 1.024 s |
| 墙面 | 829 | 2 | 78.98 ms | 0.152 s |
| 无球 | 763 | 80 | 136.08 ms | 0.689 s |
| 静止（低频） | 468 | 0 | 139.79 ms | 0.204 s |

四个录包的四路输出时间戳、对象数、点云空／非空一致性均通过。未进入回调数包含同步、
队列和边界影响，不等同于网络丢包。历史球检出超过 80%，但墙面和无球误报远高于原摆动
基线；相对未隔离追加组件版，无球误报也增加。因此该实验不满足整体交付标准。

本轮没有再次使用最新录包：历史负样本已明确失败，保留最新标注与上一轮结果，
不据此试验宣称最新检出率或真实录包起始延迟达标，也不继续调阈值。
原默认模式及三个实验开关的默认关闭状态保持不变。

## 合成回归与交付

开启候选提取及关联隔离的 ROS 合成回归通过：直线首次确认 0.245 秒，多目标、换向、
停止退出、丢失重获、静止抖动及四路输出断言通过。快摆命中 34/40，慢摆仍为 0/70；
稀疏观测首次确认 0.647 秒。后两项明确未达标，不能用合成直线结果代替真实录包的
起始延迟验收。此脚本不构成所有真实遮挡情形的覆盖证明。

`metrics.json` 保存完整回放统计，`duplicates.json` 保存球重复框及命中时间戳，
`hit_changes.json` 保存增减命中对照，`smoke.log`、`ctest.log`、`build.log` 保存验证。
本次交付的是默认关闭的失败实验，不是已完成动态障碍物识别修复。
