# 主体位置与双向射线对照（2026-10-10）

本轮实现用户指定的三项独立实验：发布实测主体位置、双向射线补充启动、保守静态发布抑制。正式入口仍为用户指定的 A04＋点源竞争、原生10 Hz；三个新开关默认关闭。三项实验和后备点级事件原型均已实现并完整回放，最终基线和仅主体位置均已用同一二进制完成复核。本轮没有通过联合验收的组合，不能声明满足动态避障条件。

## 固定验收

新球冻结113个时刻至少108命中，其中三帧子集27个时刻至少26命中；旧快摆45/53、慢摆59/59、另一段38/47，共142个原命中全部保留。静止467个冻结输出时刻全部覆盖且框数≤6。无球同频各阶段框数≤0/109/607/96，缺输出单独列出，不能当作减少杂框的收益。普通目标三帧，整回调p95＜100 ms，输入没有持续回调积压。

冻结命中判据仍为状态中心距可见球面标注中心＜25 cm、输出最大边长＜65 cm；缺输出记漏检。20 cm指物体真实直径，不作为点簇包围尺寸过滤门槛。累计框是误检代理，不能当作真实误检率；离线感知通过也不能代替整机规划、控制和闭环避障验证。

## 位姿和数据覆盖核对

只读核对Oct8新球包全部1727帧同时间戳TF及34595条高频里程计。113个冻结时刻最近HF相对TF位置差最大5.149 mm、角差最大0.417°；上述7个失败点最大2.076 mm、0.149°，没有依据归因于大位姿异常。带出阶段有局部159 mm/15°差异，未落在冻结球样本。此包没有此前Oct9录包6.8 m级HF跳变证据；不能把别的录包问题套用到这7个遗漏。

此比较使用离线最近header，不证明正式C++同步器具体配对，也不证明定位绝对准确。原型独立50 ms近似同步的实际配对与正式C++不同。原型43个冻结时刻无回调，但源里全113个时刻均有2.486 ms内HF；不能解释成源里没有同步消息，处理阻塞与队列配对各占多少尚无法独立区分。完整逐云及逐失败点证据见`pose_comparison.json`、`pose_comparison.md`、`compare_pose.py`。

## 后备点级遮挡事件原型

依计划实现独立点级原型并完整回放同五份输入。借鉴[作者M-detector仓库](https://github.com/hku-mars/M-detector)的遮挡运动思路；原型是帧级简化独立实现，未接正式launch，没有完整论文逐点时间、深度图库、聚类反馈和微秒延迟能力。算法不读取任何冻结球标签或特定时段。实现、实际配置、限制及启动命令见[原型说明](../test/point_event_prototype/README.md)。
