# 轨迹内部双向运动匹配实验（2026-10-16）

## 目标与实现

本轮优先降低误报：墙面、无球、静止录包各最多 4 个误报帧；历史球至少 91/113，
连续有效输入片段首次确认目标约 0.3 秒。最新录包冻结后单独报告，不要求本轮达到 80%。
检测对象包括直线、换向、摆动及其他真实动态障碍物，不要求球形、周期性或换向。
原运动证据阈值固定 0.45／0.30／0.40，新增组件及关联隔离关闭。

新增默认关闭的 `detection/object_motion_local_bidirectional_enabled`，只在
`object_motion_evidence_enabled` 路径生效。用同轨迹相邻两次实测稠密点集，比较不移动
及按实测中心位移对齐后的匹配率；正反方向分别以自己的全部查询点数为分母，距离
均为 5 厘米，包含边界。两个方向都达到移动匹配和相对静态优势才支持一次转移。
空点集、无效观测或断帧不能跨越累计证据；原始全云匹配、深度检查也必须通过。

局部条件直接并入原有三观测两转移的证据累计，不增加状态机。原候选、中心、关联、
背景与形状条件、运动幅度及 0.6 秒保持不变；ROS 消息、话题、四路输出接口不变。
静止采样变化和遮挡可能造成局部匹配不足，运动每帧位移小于匹配距离时，移动对齐相对
不移动也可能缺少优势，存在额外漏检的风险；须以实测报告。

新增参数：

| 参数（均在 `detection/` 下） | 默认值 | 含义 |
| --- | ---: | --- |
| `object_motion_local_bidirectional_enabled` | false | 启用双向局部附加条件 |
| `object_motion_local_match_fraction` | 0.60 | 两个方向各自最低移动匹配率 |
| `object_motion_local_match_advantage` | 0.20 | 两个方向各自最低移动减静态匹配差 |

实验入口（七分屏默认保持不变）：

```bash
roslaunch mot_mapping uav1_frame_event_verified.launch \
  dynamic_mode:=general object_motion_evidence_enabled:=true \
  object_motion_local_bidirectional_enabled:=true \
  object_motion_local_match_fraction:=0.60 object_motion_local_match_advantage:=0.20
```

## 评估口径

重新回放原摆动与原运动证据基线。所有录包使用同一套参数与 DEBUG 日志，单实例原速
顺序执行。固定历史 113 个有效标注及命中判据：中心距离 <0.25 米、最大边长 <0.65 米。
无输出／未处理有效标注计漏检；重复合格框只算一次命中，另报重复框帧数。

经确认没有真实动态目标的负样本，误报按非空状态帧计数，连续段及 >0.25 秒间隔定义事件。
用户补充允许其他真实动态障碍物后，核实无球录包包含手持绕行及操作者／手臂运动，
原始评估 README 也明确没有完整目标真值。因此无球全段非空数只能作为保守代理上界，
不能全部称为误报，也不能仅据此淘汰可能合格的组合。没有独立实例真值的输出保留为
未知，不当作已证实正确或错误。墙面与静止数据也须核对场景假设。此前旧报告中将
无球全段非空数直接称为误报的表述不适用于本次通用动态目标验收。
逐事件标出发布当帧有无就绪运动证据；没有就绪证据的输出依赖保持，而就绪不保证其他
刷新条件均已通过。基线摆动路径没有新运动证据，不能套用该字段判断。

九组局部阈值为匹配比例 {0.45, 0.60, 0.75} 与优势 {0.10, 0.20, 0.30}。
最宽松局部版本记录用于固定轨迹历史离线初筛。发布反馈、关联、处理积压及保持会使
实际回放不同，筛选估计不作为未经回放组合的实测结果。计数初筛通过的组合须完整回放；
若无组合通过，完整验证约定默认 0.60／0.20 后结束搜索，不扩大网格或增添过滤条件。

所有完整回放统计四路一致性、处理 P95、输出记录积压、未进入回调数；该计数包含同步、
队列及边界影响，不等同于网络丢包。静止录包实际约 3.8 Hz，不能宣称完成原生 10 Hz
静止实测。最新录包已被分析过，是既有验证集，不称为全新盲测，也不用于再次调参。

## 当前完整回放结论

该组合已确定无法通过本轮整体验收，实验默认保持关闭。

### 延迟、慢摆和稀疏观测

合成回归通过直线、多目标、换向、停止、丢失重获、静止抖动及四路一致性；直线首次
确认 0.261 秒，快摆 34/40。慢摆 0/70，稀疏观测首次确认 0.654 秒，明确未达标。

补查历史输入相机与 801 帧原生点云 ROI：约 84–86 秒机体转弯时相机朝向墙面，
约 86.688 秒球进入相机视野时已在摆动，未观察到静止转运动边界。真实起点标为未知，
不能从首个合格证据或标注时间倒推。85.042–86.542 秒 ROI 每帧只有 0–4 点；
86.641 秒首次至少六点。默认局部版首次标注命中 87.041 秒，比这个可观测性参照晚
0.400 秒，加输出积压约 0.497 秒。这只是首个六点 ROI 至首个标注命中的辅助统计，
不是实际运动起始延迟；也不能据此证明满足连续有效输入的 0.3 秒目标。
详见 `historical_onset_reviewed.json`，稀疏及不可判定片段保留。

## 冻结后既有最新录包验证

固定默认局部阈值 0.60／0.20，源码与参数哈希在运行前记录于 `final_frozen.json`。
有效运动及衰减标注命中 **198/819（24.2%）**，不确定／稀疏也按漏检计为 198/847；
全部有效标注有输出。分段为首次运动 158/335、首次衰减 7/55、交互运动 26/319、
末段衰减 7/110。三次连续有效输入子集为 198/799，稀疏或不确定部分 0/48。
旧原运动证据版既有结果为 204/819（本轮没有重跑其最新录包对照），不能声称改善。

首次确认相对冻结运动起点区间为 0.400–0.500 秒；加输出记录积压为 0.553–0.653 秒。
最新输入 1344 帧，未进入回调 0 帧，处理 P95 97.05 ms，输出积压 P95 0.173 s，四路一致性通过。

最新结果只报告，不继续调阈值。历史球四个版本均无同一球标注附近重复合格框。
墙面原始录包的相机抽取没有找到可解码 RGB 帧，已在 `wall_input_review.json` 记录；
本轮没有补成全雷达视场的实例真值。墙面非空数沿用既有墙面诊断场景口径，严格通用
目标误报验收仍有标注覆盖限制。无论该限制如何解决，默认局部版历史球 77.0% 已不达标。

## 交付结论

**未达到每个负样本最多 4 个误报帧且历史球至少 80% 的联合目标。** 双向局部匹配
对单向重叠有效，但在该数据上仍无法可靠区分墙面碎片与真实目标；高匹配阈值又会
拒绝真实球的稀疏和外观变化观测。九组筛选没有合格候选，未扩大搜索或增加新拦截规则。

新增功能、参数及测试以默认关闭的实验形式保留；七分屏默认不变。后续若继续，应先
补齐混合场景实例真值，并以本轮失败记录评估其他运动判据，不能仅凭非空框减少宣布修复。

及 Python 语法检查通过。只提交任务补丁和新增文件，原有连续性检查及其他修改保留，
