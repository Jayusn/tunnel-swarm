## 参考证据的限制与只读审查

A把启动时采集的真实世界点按当前雷达位姿投影，在0.25°角度格保留最近实际采集点，再以3 cm横向邻域和3 cm深度容差判断前景。这些坐标来自历史实际返回，但投影后的深度不是当前雷达真实返回，也不是两次独立历史雷达深度观测。两帧都得到前景，只说明相对同一启动地图的前景重复存在；新静态墙面、采样变化或位姿异常仍可能产生此证据。A和B同源于冻结点集，不能称为两种相互独立的物理运动佐证。

缺射线对应或近物遮挡不提供A前景。但已有非空世界KD树时，新区域真实点距启动地图超过6 cm会有B新点比例，即使射线为未知；“未被旧地图解释”不等于“动态”。这正是通道拐角和新墙面必须用无球分段核对的原因。

只读审查确认一处诊断限制：实际观测因候选间断而重置时，`reference_front_history`没有同步清空，重新出现的首个观测可能记录`reference_startup=true`并引用间断前比例。三次实测确认仍阻止此时发布，到第三个连续实测时旧比例已出队，未发现因此绕过三帧的发布漏洞。本轮冻结运行文件未改；后续最小修正可在清实测历史的同一分支清此已有deque，当前报告不将诊断true计作已正确发布。

`reference_supplement_only`日志计数来自背景抑制前的候选接受，不是最终真实发布框数。交付helper已将注释修正为“历史点投影”，并明确射线未知时世界NN仍可能为新点；计算逻辑与冻结运行版本去除docstring后的AST完全一致。运行版本副本及其原哈希另行保留，补充断言后44项Python回归再次通过。
